BOOSTCORE

Edytuj witrynę i zatwierdzaj zmiany prosto do GitHub. Zmiany trafiają na stronę, gdy tylko GitHub Pages zakończy wdrożenie — zwykle w ciągu minuty.

Ustawienia repozytorium
  1. Otwórz GitHub → New fine-grained token.
  2. W polu Repository access wybierz tylko repozytorium swojej witryny.
  3. W polu Permissions → Contents ustaw Read and write.
  4. Wygeneruj token i wklej go powyżej. Jest wysyłany wyłącznie do api.github.com.
  5. Jeśli repozytorium należy do organizacji, właściciel organizacji może dodatkowo musieć zatwierdzić token typu fine-grained.
